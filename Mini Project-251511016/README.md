## A.Produk
- Tujuan: membantu pengguna mengetahui apa itu Dev Circle
- Pengguna: mahasiswa aktif yang tertarik belajar coding/pemrograman.
- Pesan utama:
  - Headline: "Belajar Coding Bareng, Tumbuh Bareng"
  - Supporting statement: penjelasan singkat tentang Dev Circle sebagai komunitas belajar coding.
- Teknologi: HTML5 dan CSS3 murni, tanpa framework atau JavaScript.
- Perangkat: diuji dari lebar 320px hingga desktop.

## B. Struktur Proyek
Tulisan.html
css/
  style.css
assets/
  kegiatan-komunitas.jpg   
README.md

## C. Cara Menjalankan
1. Buka "Tulisan.html" langsung di browser,
2. Deploy ke GitHub Pages:
   - Push folder ini ke repository GitHub.
   - Aktifkan GitHub Pages di Settings > Pages, pilih branch 'main'.
   - Akses URL yang diberikan GitHub Pages.
